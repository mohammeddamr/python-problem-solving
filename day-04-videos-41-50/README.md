## Ground rules

- **No easy problems**: solve real-world, medium-hard/hard/challenging tasks.
- **Strict lesson boundary:** use only videos 1–50. No `for`, list/dict/set comprehensions, user-defined functions, modules/imports, file handling, or exception handling.
- **Do not require `break`, `continue`, or `pass`:** these are formally introduced in video 54; a correctly controlled `while` loop is enough.
- You **may** use `while`, `while...else`, `if`/`elif`/`else`, nested conditions, ternary expressions, and `in` / `not in`.
- All results must be computed dynamically from given input/data. Never hardcode sample outputs.
- For interactive problems, the example outputs omit input prompt text.
- Every problem has a detailed `README.md` and an unfinished `solution_1.py`. **No answers are provided**.
- If you discover a second approach, create `solution_2.py` yourself and compare in the problem README.
- For the bonus, write all predictions in the README **before** running the file.

## Suggested workflow

1. Open the problem's `README.md`, review constraints, and predict your approach.
2. Write your own solution in `solution_1.py`, based on the starter input.
3. Test with the sample data and modify it to check that your solution is general.
4. Record your **My Approach** and **What I Learned** in the README.
5. Add `solution_2.py` only if you have a distinct alternative solution.
6. Commit each solved problem separately to your existing `python-problem-solving` repo.

## How to install this day

Extract the ZIP and move the **single folder** `day-04-videos-41-50/` directly into your existing `python-problem-solving/` repository. Don't replace your repository README or any earlier day folders.
