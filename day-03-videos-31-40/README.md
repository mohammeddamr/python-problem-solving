All previously learned string, arithmetic, list, tuple, set, and dictionary concepts are fair game.

## Ground rules

- **No easy problems.** Work through your reasoning before opening Python.
- **No concepts from lessons 41+.** Specifically: **NO** `if` / `elif` / `else`, ternary expressions, loops, user-defined functions, list/dict/set comprehensions, modules, or exception handling.
- **NO** `in` / `not in` membership operator; the course introduces membership later. Use only concepts taught through video 40.
- Output must be **derived from data/inputs**. Do not hardcode the expected results.
- For interactive problems, the displayed example output assumes the documented example input and valid data of the specified shape.
- The starter files deliberately contain **no solutions**. `# TODO` is your space to work.
- If you discover another approach, save it in `solution_2.py` without overwriting your first solution.
- For problem 07, write your prediction in its README **before** running the file.

## Workflow

1. Open `NN-problem-name/README.md` and read its requirements and constraints.
2. Write a predicted approach in your own words.
3. Implement your independent attempt in `solution_1.py`.
4. Run it and compare with the example output (where provided).
5. Add an **Approach / What I Learned / Alternative Solutions** section to the problem README.
6. Commit finished problems separately to document your progress.
