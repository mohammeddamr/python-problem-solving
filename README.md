## Repository layout

```text
python-problem-solving/
├── README.md
├── .gitignore
├── day-01-videos-01-20/
│   ├── README.md
│   └── 01-user-account-normalizer/
│       ├── README.md         # Problem statement and approach notes
│       └── solution_1.py     # My first independent solution
└── templates/
    ├── problem_README.md
    └── solution_template.py
```

Each challenge gets its own folder. If I find another solution, I add `solution_2.py` (and more if useful), and explain the difference in the challenge README.

## How to run a solution

From the repository root:

```bash
python3 day-01-videos-01-20/01-user-account-normalizer/solution_1.py
```

No third-party packages are needed for Day 01.

## My practice rules

- Solve problems independently before reviewing alternative approaches.
- Practice **medium–hard and challenging** problems rather than beginner drills.
- Use only features covered by the videos completed so far.
- Preserve my first working approach and add separate files for meaningfully different solutions.
- Explain trade-offs and update progress as I complete challenges.
