# Gaming Leaderboard Engine

**Difficulty:** Hard  
**Topics:** Lists, sets, sorting, indexing, formatting  
**Status:** Not solved

## Problem

Build a leaderboard of the three highest **distinct** scores while keeping track of the original player score list.

## Given

```python
scores = [88, 95, 88, 91, 74, 95, 82, 91, 99, 74]
```

## Requirements

1. Keep `scores` unchanged.
2. Make a separate list of all scores sorted in descending order (including duplicates).
3. Create a new list of unique scores, sorted in descending order.
4. Get the top three distinct scores.
5. Count how many players scored exactly `95`.
6. Find the first index of `91` in the **original** score list.
7. Print a three-line leaderboard using the values from the distinct-score list.

## Expected output

```text
Sorted Scores:
[99, 95, 95, 91, 91, 88, 88, 82, 74, 74]

Unique Top 3: [99, 95, 91]
Players with 95: 2
First 91 Index: 3

LEADERBOARD
1st: 99
2nd: 95
3rd: 91
```

## Constraints

Do not manually remove duplicates one by one; use a suitable data structure. No loops, conditions, custom functions, or hardcoded ranking scores.

## Extra challenge

Explain why a set alone is not sufficient for printing a ranked leaderboard.
